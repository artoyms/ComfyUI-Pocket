# ComfyUI-Pocket

Free, open-source ComfyUI extension used by **PocketComfy**, a remote control for ComfyUI on your own PC from Android, Windows and iOS.

It adds a small API to ComfyUI: history with live progress (including generations started from other devices), gallery with search, favorites, ratings and collections, safe delete with trash, queue control, model downloads, and thumbnails.

## Install

**ComfyUI-Manager:** search for `ComfyUI-Pocket` and install, then restart ComfyUI.

**Manually:** copy this folder to `ComfyUI/custom_nodes/ComfyUI-Pocket` and restart ComfyUI.

Then start ComfyUI so other devices can reach it (`--listen`) and connect from the app.

## The app

PocketComfy for Android and Windows (iOS coming): https://boosty.to/exgirlfriend
Every device gets 5 free trial generations.
